# 岗位批次筛选与卡片标识

## 目标

- 移动端筛选面板的两个操作按钮等宽，并统一使用“应用筛选”。
- 岗位卡片左上角展示来源数据中的原始 `batch`，不再展示采集来源。
- 岗位池新增原始批次筛选，但保留 `recruitment_type` 给画像和推荐硬筛选使用。

## 实现边界

- 复用现有 `job.metadata["batch"]`，不新增数据库列，不替换飞书接口。
- 扩展现有岗位列表和筛选选项接口，新增可空 `batch`、`batches` 和 `batch` 查询参数。
- 批次按原始字段精确匹配；缺失批次仍按“未知保留”处理。

## 验证

- 后端契约、服务筛选和 HTTP query 测试。
- 前端类型、查询构造、岗位池渲染和筛选面板测试。
- Ruff、前端 TypeScript/Vitest、pytest。
