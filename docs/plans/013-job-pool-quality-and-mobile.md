# 岗位池排序、质量门禁与移动端信息压缩

## 目标

- 岗位池默认按 `published_at` 降序，发布时间未知的岗位排在最后；不再人为截断可见岗位总数。
- 解析器识别出疑似“多个岗位挤在一个标题”的结果时，拒绝直接入库，并使用飞书“招聘岗位”字段拆成独立岗位卡片。
- 移动端把岗位池总量和当前视图合并为一行，减少重复信息。

## 实现边界

- 复用现有 `JobPoolStore`、`CollectionQualityPolicy` 和表格回退链路，不新增依赖或飞书接口。
- 质量门禁支持常见标点、换行和空格分隔，同时保护括号内的说明文本；无法安全拆分时整行拒绝回退。
- 回退岗位不把整段“招聘岗位”列表写入描述，原始列表和批次保留在 metadata 中。
- 不对历史数据库做自动关闭或删除；不完整采集仍不能关闭历史岗位。

## 验证

- 后端岗位池排序、超过 5000 条、质量门禁和表格回退测试。
- 前端岗位数量工具栏、筛选契约和生产构建测试。
- Ruff、mypy、pytest。
